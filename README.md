## About Me
> I build microservices using Python + FastAPI + MSSQL/SQLite and integrate with a variety of external APIs. I also automate deployments and manage Linux servers using Ansible + Docker + Hashicorp Vault + Sentry + Github Actions. On the frontend side, I work with React + DevExtreme + Radix + Vite.
> 
> Outside of work, I maintain a home server that serves as a playground for experimenting with new tools and ideas. I continuously learn, test approaches, review code designs, take courses, create pet projects and look for more ways to deepen my knowledge.
